# Named packages/modules excluded from the Nuitka build via --nofollow-import-to=<name>.
#
# One dotted name per line; `#` starts a comment. NEVER a glob -- build_installer.ps1 and
# scripts/check_nofollow_allowlist.py both reject `*`/`?`/`[`. The last blanket
# `*.tests`/`*.testing` exclusion also caught structlog.testing, jinja2.tests, and
# scipy._external.array_api_extra.testing, which runtime code imports unconditionally, and
# the packaged app crashed on every invocation (packaging/RELEASE_RUNBOOK.md).
#
# Admission rule, enforced before every build by scripts/check_nofollow_allowlist.py against
# the build venv's site-packages: nothing outside this list (other than test code: conftest.py,
# test_*.py) may import an entry, statically or as a dotted string literal. Every entry must
# also exist, so a numpy/scipy upgrade that moves a test dir fails loudly instead of the
# exclusion silently no longer applying.
#
# Why these: reports/build-timing/2026-09-23-attempt2-partial/summary.md -- numpy/scipy test
# suites measured at 84.3 min of the first 279.6 min of C compile (204 numpy + 117 scipy test
# modules), plus 270 not-yet-compiled scipy test modules (411.6 MB of generated C).
#
# Deliberately NOT listed: numpy.testing (numpy/__init__.py's lazy __getattr__ imports it),
# scipy._lib._testutils, structlog.testing, jinja2.tests, scipy._external.array_api_extra.testing
# -- all imported by runtime code.
